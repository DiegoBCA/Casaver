# Casaver

Welcome to Casaver, a modern, animated React application built for an esoteric and holistic brand.

## 🚀 Technologies Used
- **React 19**
- **Vite** for blazing fast builds and HMR.
- **Tailwind CSS v4** for utility-first styling.
- **Framer Motion** for smooth and complex animations.
- **Lenis** for buttery smooth scrolling experiences.
- **React Router** for seamless navigation.

## 📦 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Run the development server:**
   ```bash
   npm run dev
   ```
3. **Build for production:**
   ```bash
   npm run build
   ```

## 📂 Project Structure
- `/src/components`: Reusable UI components (e.g., `Hero`, `ProductGrid`, `Newsletter`).
- `/src/pages`: Application views.
- `/src/context`: React Context providers for state management (e.g., `CartContext`).
- `/public`: Static assets, images, and product mockups.
